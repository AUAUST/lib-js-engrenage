# #163 codegen: slow generator run

- State: CLOSED
- Labels: 🐛 – Bug: Medium

## Body

Part of #137, under #158. Meant for a debugger: investigate, fix at the root when the fix is contained, otherwise write the fix into this issue.

## Context

`pnpm ready` runs `pnpm run support codegen`, that is `node scripts/support/index.ts codegen`, which runs every generator of `scripts/support/codegen/` (`editions`, `apis`, `rules`, `config`, `barrels`). It takes very long, which slows `ready` and every regeneration. Nothing records where the time goes. #147 later moves these generators to `scripts/codegen/`; a cause found here should be fixed before it, or written into #147.

## Prerequisites

None.

## Steps

1. Measure the wall time of `node scripts/support/index.ts codegen` and of each generator run alone (`pnpm support codegen <generator>`), with and without `--check`.
2. Inside the slowest generators, measure module loading and startup, network or registry requests, TypeScript program or type-checker creation, filesystem scans, and formatting of the written files, repeated per file or per generator.
3. Record the findings here: total and per-generator times, where each one spends its time, and the cause.

## Done when

This issue records where codegen spends its time and its cause, and the cause is fixed or its fix is written here or into #147.
