# #156 cli: report of the resolved project structure

- State: OPEN
- Labels: 🚀 — Feature

## Body

Part of #137, step 3. Read the plan, its **Core model**, **Tests layout** and **Strictness and the structure report** sections, and #148 and #164, before starting.

## Context

The structure description (#148) classifies every directory from configuration, preset defaults and filesystem inference. A misclassified directory silently skews every consumer: aliases, lint scope, boundaries, agent guidance. Nothing shows how engrenage reads a codebase, so a command prints the resolved structure and checks it, before the relocation of `src/` (#139) relies on it.

Decided:

- `engrenage structure`, a discovered command in `bin/engrenage/structure.ts`, which only parses input and prints; resolution and rendering live in `src/project/structure/`, reusing the resolved structure of #148, never a second walk.
- Output: one line per directory with its classification (namespace with its layers, domain with its visibility, role, tests mirror with the path it mirrors (#164), unclassified with its reason when it has one) and source (`config`, `preset`, `inferred`), grouped by environment.
- `--check` exits non-zero when a `strict` environment holds an unclassified directory; `loose` environments are reported, never failing.

## Prerequisites

- #148 is closed.
- #164 is closed.

## Steps

1. Add the rendering of the resolved structure to `src/project/structure/`.
2. Add the command and its `--check` mode.

## Tests

- A fixture with an unknown directory in a `strict` environment: reported as unclassified, `--check` fails; the same fixture as `loose`: reported, `--check` passes.
- Namespaces print their layers and every line its source.
- A `mirror` tests environment with a directory lacking its counterpart: printed with its reason, `--check` fails.

## Done when

`engrenage structure` prints every directory's classification and source, `--check` fails only on unclassified directories of `strict` environments, and the project's checks pass.
