# c12

Upstream c12 configuration loader issues.

## 1. c12 type-imports its optional peer giget.

- why: `c12/dist/index.d.mts` imports `DownloadTemplateOptions` from `giget`, an optional peer engrenage does not install, so type checks with `skipLibCheck: false` (the dist type check, `tsconfig.tests.dist.json`) fail. An ambient `giget` module in `env.d.ts` stands in for it.
- want: c12 stops type-importing giget from its public types (or engrenage moves from `c12@4.0.0-rc.3` to the stable `c12@4`, if fixed there).
- done: `env.d.ts` is deleted.
