# Project map

Generated by `engrenage sync agents` from the project structure. Do not edit.

## Notation

| Mark     | Kind       | What it is                                                 | Imports                                                                                  |
| -------- | ---------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `name/`  | namespace  | groups children; no `index.ts`, no roles                   | —                                                                                        |
| `a < b`  | layers     | order of a namespace's children, lowest first              | a child imports lower layers and same-layer peers through their `index.ts`; never higher |
| `name`   | domain     | one concern behind `index.ts`; holds roles and sub-domains | own roles; global roles; what its namespace's layers allow                               |
| `name*`  | domain     | public: `@auaust/engrenage/<name>`                         | as a domain                                                                              |
| `a{b c}` | sub-domain | domain inside domain `a`                                   | ancestors' roles directly; `a` reaches `b` only through `b/index.ts`                     |
| `#x/…`   | alias      | the only specifier for `x`; nested domains get none        | —                                                                                        |

Unlisted layers: children are unordered peers.

## Structure

```
src/                 foundation < project < tools < workflows      global roles: index.ts constants.ts types/ utils/
├─ foundation/       #foundation/…   blocks data filesystem json options processes
├─ project/          #project/…      baseline*{editions} build config* environments format* package*
│                                    presets steps structure tsconfig workspaces
├─ tools/            #tools/…        agents*{claude* codex*} changesets* eslint* git* github* pnpm*
│                                    prettier* tsdown* typescript* vite* vitest* vscode*
└─ workflows/        #workflows/…    cli init registry sync
bin/engrenage/       #bin/…          agents{claude{hook} codex{hook}} pnpm         thin commands, no roles
scripts/             #scripts/…      codegen
tooling/             —               config files only
tests/               #tests/…        mirror: bin/ scripts/ src/ each mirror their environment
```

## Roles

Same catalogue in `src`, `scripts`, `tooling`, `tests`; `tests` adds `fixtures/` (any nesting) and `setup.ts`.

| Role                               | Holds                                               | Imports beyond its domain's                                                                               |
| ---------------------------------- | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `index.ts`                         | the domain's surface                                | —                                                                                                         |
| `constants.ts`                     | the domain's fixed values                           | —                                                                                                         |
| `types/`                           | one type per module                                 | only `types/` here and above; other domains' `index.ts` type-only                                         |
| `utils/`                           | pure functions, one per module                      | only `utils/`, `types/`, `constants.ts` here and above, global roles; other domains' `index.ts` type-only |
| `config/` (`schemas/` inside)      | option declarations                                 | —                                                                                                         |
| `setup/`                           | init steps, sync targets                            | —                                                                                                         |
| `operations/`                      | impure logic, definers                              | —                                                                                                         |
| `plugins/`                         | the tool's own plugins                              | —                                                                                                         |
| `enums/`                           | enums                                               | —                                                                                                         |
| `conventions/`                     | discovered conventions, by category, default export | —                                                                                                         |
| `ports/` · `adapters/` · `errors/` | interfaces · their implementations · errors         | public: importable module by module                                                                       |

"Here and above": the domain and its ancestors. Global roles import only each other.
