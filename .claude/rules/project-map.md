## Imports between environments

- src environment: never: src never imports bin → bin
- src environment: never: src never imports scripts → scripts
- src environment: never: no environment imports tests → tests
- src environment: never: a library's src never imports data/ → data
- src environment: a library's src reads data/ at runtime through the public specifier → data (not enforced by lint)
- bin environment: bin commands are thin and use all of src → public-entries, internal-aliases
- bin environment: bin imports its own command tree → bin
- bin environment: never: bin never imports scripts → scripts
- bin environment: never: bin never reads data/ directly → data
- bin environment: never: no environment imports tests → tests
- scripts environment: scripts use all of src → public-entries, internal-aliases
- scripts environment: scripts import their own modules → scripts
- scripts environment: never: scripts never import bin → bin
- scripts environment: never: no environment imports tests → tests
- scripts environment: scripts read and write data/ by path (generated files) → data (not enforced by lint)
- tooling environment: a library's tooling imports public entries only → public-entries
- tooling environment: never: a library's tooling never imports src internals → internal-aliases
- tooling environment: never: tooling never imports bin, scripts or data/ → bin, scripts, data
- tooling environment: never: no environment imports tests → tests
- tests environment: tests spawn bin commands → bin (not enforced by lint)
- tests environment: a library's tests read data/ at runtime through the public specifier → data (not enforced by lint)
- test files `**/*.{spec,test}.{ts,tsx}`: x.test.ts runs in source and dist mode, so it imports the package name → public-entries, tests, scripts
- test files `**/*.{spec,test}.{ts,tsx}`: never: x.test.ts never imports internals or bin modules; those belong to x.test.src.ts → internal-aliases, bin
- test files `**/*.{spec,test}.src.{ts,tsx}`: x.test.src.ts runs in source mode only and reaches internals through #… aliases → internal-aliases, bin, tests, scripts
- test files `**/*.{spec,test}.src.{ts,tsx}`: never: x.test.src.ts never imports the package name → public-entries
- test files `**/*.{spec,test}.dist.{ts,tsx}`: x.test.dist.ts runs in dist mode only and may reach dist-only artefacts → public-entries, tests, scripts, dist-artefacts
- test files `**/*.{spec,test}.dist.{ts,tsx}`: never: x.test.dist.ts never imports internals or bin modules → internal-aliases, bin
