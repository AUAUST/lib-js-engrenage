# #151 agents: project map generated from the project structure

- State: OPEN
- Labels: 🚀 — Feature

## Body

Part of #137, under #149. Read the plan, its **Core model**, **Environments**, **Inside a domain** and **Roles** sections, and #148, before starting.

## Context

`AGENTS.md` describes the directory structure in prose ("Project map", "Modules and exports"), which drifts from the code. `engrenage sync agents` already writes agent files from fragments and references. Agents must write compliant code from the start rather than learn the structure from lint failures, so they need upfront guidance; the structure description (#148) can generate it, so it never drifts.

Decided:

- Content generated from the resolved structure: per namespace, its path and layers; per domain, its path, namespace and layer, visibility, purpose, sub-domains and allowed dependencies; per role, its contents, allowed imports, contract and whether it is public.
- Allowed dependencies and imports are rendered from the import rules resolved in `project/structure` (#162), the same source #150 lints from, with their reasons; rules #162 flags as not enforceable by import analysis (runtime references to `data/`, `bin` being spawned) are rendered too, since nothing else carries them.
- The `tests` environment is described by its layout (#164): its root keys, its roles and whether it mirrors the tested environments.
- Delivery: a fully generated rule file, `.claude/rules/project-map.md`, with its Codex mapping, loaded at start, regenerated by `engrenage sync agents` and checked by `--check`.
- The axiom in `AGENTS.md` pointing to it is written by #152, which rewrites the instructions with the maintainer's consent; this task changes no written instruction.

## Prerequisites

- #148 is closed.
- #162 is closed.
- #164 is closed.

## Steps

1. In `tools/agents`, render the project map from the resolved structure.
2. Add it to `engrenage sync agents` (write and `--check`), with the Codex mapping.

## Tests

- A fixture's description renders the expected map: a namespace with layers, a public domain, a project-defined role.
- `--check` fails when the map is stale.

## Done when

`engrenage sync agents` writes and checks the generated project map for this repository, and the project's checks pass.
