# Planning draft

Read `.claude/rules/issues.md` and `.claude/rules/issue-drafts.md` before your first draft.

1. Ask the user whether to start drafting a plan. On no, leave the backlog entry needing planning.
2. On yes, create a `plan` draft holding the compass, the settled decisions and the items found so far as child drafts, each with its **Context**; put the implications found and what a planner must still design under **Planning**, and what the user still owes under **Questions**.
3. Update it as the discussion settles points; drop from it each item a dispatched fix or groundwork commit finishes.
4. Give the user the plan draft's path, for a planning session to start from; publish it only on the user's word.
