# #157 config: workspaces with generated package files

- State: OPEN
- Labels: 🚀 — Feature

## Body

#137 › #161 · §Imports: workspaces row

## Context

Engrenage models one package. A Shopify app's `extensions/*` are pnpm workspaces, each with a hand-written minimal `package.json` and a `tsconfig.json` extending the root; some hold components, discovered routes and GraphQL documents, and Shopify Functions have their own structure and runtime. Node subpath imports cannot cross packages (`ERR_INVALID_PACKAGE_TARGET` for `../../src/*`), so shared code reaches workspaces only through the `src` bundler aliases (#159), which needs `src.bundled`. Decided: engrenage never models the host platform (its CLI, TOML files, codegen configuration, locales, Wasm builds).

## Steps

1. Declare a `workspaces` option: globs, each mapped to a name pattern with `{dir}` interpolation (`@scope/app-{dir}`), an environment and a tsconfig; one environment per glob, each workspace a domain root inside it; workspaces needing another structure or runtime get their own glob (`extensions/functions-*` beside `extensions/action-*`).
2. Keep `pnpm-workspace.yaml#packages` in line with the globs, through one `pnpm-workspace.yaml` sync target in `tools/pnpm` shared with #53's settings, created here if #53 has not landed.
3. Add sync targets for each workspace's `tsconfig.json` and its managed `package.json` keys, preserving every other key: `name` from the pattern, `private`, `version` and `license` from the root, and

   ```json
   "imports": { "#self/*": { "types": ["./src/*.ts", "./src/*.tsx"], "default": "./src/*" } }
   ```

4. Derive build entries (one per workspace), Vitest includes and the ESLint scope from the declaration.
5. Add the workspaces row of §Imports to the import rules of `project/structure` (#162).

## Tests

- A fixture with two globs (`extensions/action-*`, `extensions/functions-*`): `pnpm-workspace.yaml#packages`, each `package.json` (name from `{dir}`, `#self/*` imports, a foreign key preserved) and each `tsconfig.json` match; `--check` reports drift.
- A workspace module importing `#self/…` and a `src` alias type-checks and builds through Vite.
- The resolved import rules forbid a workspace's import of another workspace that is not a declared dependency.
