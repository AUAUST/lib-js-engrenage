## Context

Public entries are discovered from tsconfig `paths` that `src.exports` maps by hand. Toolkit and other libraries need engrenage's capabilities: write valid files formatted by the project's formatter, and read engrenage's understanding of a project. Formatting is wired by hand: `foundation/filesystem` receives a Prettier-backed formatter from `project/config`, and the agents domain spawns a process.

## Steps

1. Derive the public entries (tsconfig `paths`, package exports, entry discovery) from `domains.<path>.public` (#148):
   - a public domain's specifier is its `specifier` when declared, otherwise its path without namespaces (`tools/tsdown` → `./tsdown`, `tools/agents/claude` → `./agents/claude`, `project/config` → `./config`); two public domains with one specifier fail;
   - an internal domain gets no package export and no tsconfig `paths` entry, so its specifier resolves in neither mode; nothing is declared to make a domain internal;
   - a public role becomes a package export only when its domain is public and its index re-exports it;
   - `src.exports` keeps only exports that are not domain entries (`./constants`, `./*/constants`); drop the others from engrenage's, run `pnpm build:tsdown` and commit the regenerated `package.json`.
2. Declare the port in `project/formatting/ports/Formatter.ts`, implement it in `tools/prettier/adapters/`, and inject it from `workflows` wherever formatting happens (staged filesystem, agents' edited files), replacing the spawned formatting. `project/formatting` exposes `formatContent(content, { path, root })`, returning the formatted string, and `formatFile(path, { root })` built on it.
3. Expose `loadConfig(root)`, the `package.json` model and the baseline through their domains' `index.ts`; `project/structure`'s resolved structure reaches consumers through `loadConfig`.
4. Turn the `x.test.src.ts` tests that the new public entries cover into `x.test.ts`.

## Tests

- `formatContent` formats a TypeScript string with the project's Prettier options; `formatFile` rewrites a file in place.
- An internal domain gets no export; a public one gets its default specifier, or its declared `specifier`.
- `@auaust/engrenage/project/structure` resolves in neither source nor dist mode.

## Done when

The formatting contract is the only path to the formatter.
